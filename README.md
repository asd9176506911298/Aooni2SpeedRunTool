# Aooni2SpeedRunTool

# Install BepinEx

https://builds.bepinex.dev/projects/bepinex_be

BepInEx-Unity.IL2CPP-win-x64-6.0.0-be.788+5b766a3.zip

# Features

F1：NoClip（すり抜け）

F2：セーブステート（状態保存）

F3：ステート復元（状態ロード）

F4：無敵

F12：現在のセーブデータを再読み込み (リロード)

テンキー +：移動速度アップ (Add MoveSpeed)

テンキー -：移動速度ダウン (Minus MoveSpeed)

テンキー *：通常速度とカスタム速度の切り替え (Toggle Between origin and custom MoveSpeed)

テンキー 0：デフォルトの移動速度にリセット (reset to default MoveSpeed)

マップテレポート (Map Teleport)

全アイテム追加 (Add All Item)

マップ名表示 / (Show Map Name)

移動軌跡表示 (または 移動経路表示)

召喚鬼 (あくまで遊び用として、ゲーム内のキラーのストックを変更するものです)
